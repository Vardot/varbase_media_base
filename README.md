# Varbase Media Base

A base recipe to install core media modules and apply default Varbase media configurations including media library, focal point, and media types.

## Features

- Media library and media types (audio, file, gallery, image, remote video, video)
- Focal point image cropping
- Bulk media upload support with Dropzone
- Media library editing capabilities
- Views integration for media management

## Installation

This recipe is designed to be used as part of Varbase installation or applied to existing Drupal sites.

```bash
php core/scripts/drupal recipe varbase_media_base
```
